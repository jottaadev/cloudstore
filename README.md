# 🌩️ ZyexCloud Store

Uma plataforma moderna de cloud gaming e computação em nuvem, construída com Next.js 14 e tecnologias de ponta.

## ✨ Features

- 🎮 **Cloud Gaming** - Jogue seus jogos favoritos diretamente na nuvem
- 💻 **Workstations Virtuais** - Ambientes de trabalho completos na nuvem
- 🚀 **Performance Extrema** - Infraestrutura otimizada para máxima performance
- 🔒 **Segurança Avançada** - Proteção de dados de nível empresarial
- 📱 **Design Responsivo** - Experiência perfeita em todos os dispositivos
- 🎨 **Interface Moderna** - UI/UX cuidadosamente crafted

## 🛠️ Tech Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Package Manager:** pnpm

## 🚀 Getting Started

### Pré-requisitos

- Node.js 18+ 
- pnpm

### Instalação

1. Clone o repositório
```bash
git clone https://github.com/jottaadev/cloudstore.git
cd cloudstore
```

2. Instale as dependências
```bash
pnpm install
```

3. Execute o projeto em modo desenvolvimento
```bash
pnpm dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador

## 📦 Scripts Disponíveis

- `pnpm dev` - Executa em modo desenvolvimento
- `pnpm build` - Gera build de produção
- `pnpm start` - Executa a versão de produção
- `pnpm lint` - Executa o linter
